# Privacy Policy for Noiseless

Noiseless does not collect, store, or transmit any personally identifiable information (PII).
- All API keys, settings, and keywords are stored strictly within the user's local browser storage (chrome.storage.local).
- Text sent for analysis is transmitted directly from the client browser to the respective LLM provider APIs (e.g., Google, Zhipu, Atria, Tavily) chosen by the user.
- We do not run any intermediary servers, tracking scripts, or analytics.
